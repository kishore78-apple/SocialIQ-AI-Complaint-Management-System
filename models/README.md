# Trained Models

This folder contains the trained machine-learning model files used by the SocialIQ AI Complaint Management System.

The models are loaded by the backend service modules to generate predictions for citizen complaints.

## Model Categories

The models support different AI modules including:

- Department Prediction
- Sentiment Analysis
- Feedback Category Prediction
- Priority Prediction
- Emergency Detection
- Harmful Content Detection
- Trend Forecasting
- Anomaly Detection
- Government Action Recommendation

## Important

The model files are provided for running the application and reproducing the project workflow.

Large training datasets and unnecessary duplicate model files are not included in the repository.
