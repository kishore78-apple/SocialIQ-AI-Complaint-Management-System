# Model Evaluation Results

This folder contains selected evaluation results generated during the development and testing of the SocialIQ AI Complaint Management System.

## Included Modules

The results cover the following machine-learning modules:

- Complaint Reason Classification
- Department Prediction
- Priority Prediction
- Emergency Detection
- Harmful Content Detection
- Trend Forecasting
- Anomaly Detection
- Government Action Recommendation

## Purpose

These files provide supporting evidence for the performance and evaluation of the machine-learning models used in the project.

Only selected evaluation files are included to keep the GitHub repository organized and lightweight.

## Data Privacy

Raw citizen complaint datasets and large training files are not included in this repository.
